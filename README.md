# 🌦️ Weather Data Analysis and Prediction

This project is about understanding weather data step by step and learning how different weather factors are connected to each other.  
Instead of jumping directly into prediction, the focus here is on **cleaning the data, exploring it properly, and then applying machine learning in a meaningful way**.

I worked with real-world weather data to improve my skills in data analysis, visualization, and basic machine learning.

---

## 📌 Why I Did This Project

Weather data looks simple on the surface, but it contains many hidden relationships.  
Through this project, I wanted to:
- Understand how temperature changes with humidity, wind, and pressure
- Learn how to handle real datasets that are not perfectly clean
- Apply machine learning concepts in a practical and understandable way

This project helped me move from just learning theory to actually using it.

---

## 📂 About the Dataset

The dataset contains historical weather records with information such as:

- Date and time of observation  
- Weather summary and precipitation type  
- Temperature and apparent temperature  
- Humidity  
- Wind speed and direction  
- Visibility and cloud cover  
- Atmospheric pressure  
- Hour and month  

These features allowed me to study both **short-term (hourly)** and **seasonal** weather patterns.

---

## 🛠️ Tools & Technologies Used

- **Language:** Python  
- **Libraries:** NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn  

These tools were used for data cleaning, visualization, and building machine learning models.

---

## 🔍 What I Did in This Project

### 1. Data Preparation
- Converted date and time into usable formats
- Handled missing and inconsistent values
- Selected useful features for analysis and prediction

### 2. Exploratory Data Analysis (EDA)
- Studied distributions of temperature, humidity, and wind
- Used graphs to understand trends and correlations
- Observed how weather changes across different hours and months

### 3. Machine Learning
- Applied regression models to predict temperature
- Split data into training and testing sets
- Evaluated model performance to understand accuracy and limitations

---

## 📊 What I Learned

- Weather variables are strongly connected and influence each other
- Clean data makes a big difference in model performance
- Visualizing data helps in understanding patterns before modeling
- Machine learning works best when the fundamentals are clear
